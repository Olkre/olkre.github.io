CSIS2023 Assignment 1: Create a basic website for a fictional car dealership.
You will create two pages for a fictional car dealership. This is more about functionality than
graphics design skill, but you should attempt to produce a reasonably viewable layout.
Before starting, please read about HTML tables at
https://www.w3schools.com/html/html_tables.asp
The first page (index.html) should contain:
- Valid HTML boilerplate
- A title tag
- A logo / title for the page w/ image
- A heading tag for “Cars Currently Available”
- A table that contains the following (at least 3):
o An image of the car
o Make
o Model
o Year
o Link to view more (a link to details.html) – note that all links go to same page
- A footer with a copyright message
The second page (details.html) should contain:
An expanded version of the information in the first page (larger image, make, model,
year)
